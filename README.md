# ARTEFACT PC Builder
Configuratore demonstrativ PWA, adaptat pentru mobil, tabletă și desktop.

## Publicare GitHub Pages
Repository: https://github.com/bxBlumix/artefact-pc-builder
În GitHub: Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.
După publicare: https://bxblumix.github.io/artefact-pc-builder/

## Instalare pe Android
Deschide adresa publicată în Chrome → meniul ⋮ → „Instalează aplicația” sau „Adaugă la ecranul principal”.

## Limitări
Catalogul este demonstrativ (modele reprezentative), iar prețurile sunt estimări statice în RON, nu prețuri live. Imaginile sunt pictograme, iar prototipul vizual este o machetă conceptuală, nu un model 3D exact. Verificarea compatibilității este orientativă; confirmă toate detaliile în manualele producătorilor.
